# Optymalny rozkład użytków

Prosta aplikacja webowa do rozmieszczania prostokątnych użytków na arkuszu lub płycie.

## Publikacja na GitHub Pages
1. Utwórz nowe repozytorium na GitHubie.
2. Wgraj wszystkie pliki z tego folderu do głównego katalogu repozytorium.
3. Wejdź w **Settings → Pages**.
4. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
5. Wybierz branch **main** i folder **/(root)**.
6. Zapisz ustawienia.

Po publikacji aplikacja będzie dostępna pod adresem podobnym do:
`https://twoj-login.github.io/nazwa-repozytorium/`

Na telefonie można dodać ją do ekranu głównego z menu przeglądarki.
